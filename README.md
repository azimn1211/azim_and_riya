# Azim & Riya — Nikah invitation website

A single-page, animated wedding invitation for **Thursday, 19 November 2026**
(9 Jumadal Ukhra 1448), Vallakkadavu, Thiruvananthapuram.

Everything that gets published lives in `website/` (plain HTML/CSS/JS, no build
step, ~1.5 MB). `tools/` holds the scripts that painted the artwork; they are
not needed to host the site.

## What's on the page

1. **Sealed card intro** on a plum backdrop with an Islamic star lattice and
   falling petals. *Open Invitation* breaks the seal, flowers fly at the
   viewer, petals burst out and the card lifts away.
2. **Hero:** السَّلَامُ عَلَيْكُمْ and the names inside a watercolour wreath.
3. **Invitation** from Mr. Nisamudeen & Mrs. Safiya, worded as on the card.
4. **Qur'an 30:21** in Arabic with its meaning.
5. **The Nikah:** date badge (like the printed card), Hijri date, time, masjid
   and venue, live countdown, calendar and *Add to Calendar*. A *Confirm
   Attendance* button (opens WhatsApp) appears once Azim's number is set.
6. **Finding us:** Google Maps for the masjid and the convention centre, with
   directions.
7. **Best wishes** and a **du'a for the newlyweds** in a mihrab arch.
8. **Footer** with the family's thanks and a flower bed.

Motion: swaying branches, layered parallax (faint background branches drift
slower than the page, edge branches faster), scroll reveals, and
**auto-scroll** (50 px/s, starts 2 s after opening). Scrolling by hand pauses
it; tapping the page or the round button resumes it. Mouse-wheel scrolling is
eased so the page glides instead of jumping; touch scrolling stays native.
Visitors who have "reduce motion" turned on get a still page.

## Preview on your computer

```bash
python3 -m http.server 8765 --directory website
```

Then open http://localhost:8765.

## Personalised links

Add `?to=` with the guest's name. The card greets them by name (and, once the
RSVP button is on, the WhatsApp message includes it):

```
https://azimandriya.vercel.app/?to=Rahul%20%26%20Family
```

(`%20` is a space and `%26` is `&`.)

## Changing details

| What | Where |
| --- | --- |
| Text on the page | `website/index.html` |
| Nikah time (countdown, calendar files) | `CONFIG.nikah` / `CONFIG.nikahEnd` in `website/js/main.js` |
| Confirm Attendance (WhatsApp) | `CONFIG.whatsapp` in `website/js/main.js`: Azim's number with country code and no `+`, e.g. `'919876543210'`. Empty hides the button. |
| Map pins | `CONFIG.places` in `website/js/main.js` (pinned by coordinates; a text search finds a different mosque) |
| Auto-scroll speed | `CONFIG.scrollSpeed` in `website/js/main.js` |
| Parallax strength | `CONFIG.parallax` in `website/js/main.js` (1 = subtle, 3 = current) |

### Optional photo gallery

A 3D cover-flow gallery is built in but hidden. To show it, put photos in
`website/assets/photos/` and list them in `CONFIG.photos`, e.g.
`photos: ['assets/photos/1.jpg', 'assets/photos/2.jpg']`.

## Hosting

The site is live at **https://azimandriya.vercel.app**. It is hosted by the
Vercel project `azim_and_riya` on Azim's account, which is connected to this
repository: every merge into `main` deploys to production automatically, and
other branches get preview deployments. `vercel.json` tells Vercel to serve the
`website/` folder with no build step.

The repository is public because Vercel's free Hobby plan only deploys the
owner's commits from a private repository.

WhatsApp and other link previews read `og:url` and `og:image` in
`index.html`. They must be full URLs, so update both if the address changes.

## Branches

`main` is what is live. Work goes on a feature branch, is merged into
`development` by pull request, and `development` is merged into `main` once
checked.

## Artwork

All flowers are original watercolour paintings generated by code in the
palette of the printed card: slate-plum peonies, peach roses, dark fronds and
gold leaves. To repaint them you need Python with `pycairo`, `numpy`, `scipy`
and `pillow`:

```bash
python3 tools/paint_assets.py              # every flower asset
python3 tools/paint_assets.py wreath       # one asset by name
python3 tools/paint_paper.py               # paper texture
```

The link-preview image is rendered from `tools/og.html` with headless Chrome:

```bash
google-chrome --headless=new --hide-scrollbars --allow-file-access-from-files \
  --window-size=1200,630 --virtual-time-budget=8000 \
  --screenshot=og.png "file://$PWD/tools/og.html"
```

Fonts come from Google Fonts (Great Vibes, Viaoda Libre, EB Garamond, Amiri),
all under the SIL Open Font License.
